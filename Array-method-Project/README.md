# 📊 Array Methods Project

A simple and interactive web application to learn and test JavaScript array methods in real-time.

🔗 **Live Demo:** https://array-method-project.netlify.app/

## 🚀 Features

* Input custom array values
* Apply multiple JavaScript array methods
* Instant output display
* Beginner-friendly UI using Bootstrap
* Covers both basic and advanced array methods

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript 
* Bootstrap 5

---


## 📥 How to Use

1. Enter array values (comma-separated)
   👉 Example: `1,2,3,4,5`

2. Enter a value (if required by method)

3. Select an array method from dropdown

4. Click **"Check"**

5. View the result instantly

---

## 📌 Supported Array Methods

* push
* unshift
* pop
* shift
* length
* toString
* reverse
* indexOf
* includes
* sort (ascending & descending)
* map
* filter
* some
* every
* find
* findIndex
* reduce

---


## 💡 Example

**Input:**

```
Array: 1,2,3,4
Value: 2
Method: map
```

**Output:**

```
[2, 4, 6, 8]
```
