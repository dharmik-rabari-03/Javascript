📌 Project Overview

EasyProduct is a simple E-commerce CRUD (Create, Read, Update, Delete) application built using HTML, CSS, JavaScript, and Bootstrap.

This project is created as a JavaScript practice to understand DOM manipulation and CRUD operations.

🚀 Features
✅ Display product list (Read)
➕ Add new product (Create)
✏️ Edit product details (Update)
❌ Delete product (Delete)
🛒 Add to cart alert (basic functionality)
📱 Responsive UI using Bootstrap

🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Bootstrap 5
