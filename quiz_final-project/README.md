# Quiz Application 🎯

A simple and interactive Quiz Application built using **HTML, CSS, and JavaScript**. This app allows users to answer multiple-choice questions and view their final score along with correct answers.

---

## 🚀 Features

* Multiple-choice quiz questions
* Instant navigation to the next question after selection
* Score tracking system
* Final result display with correct answers
* Clean and responsive UI

---

## 🧠 Quiz Topics Covered

* HTML basics
* CSS fundamentals
* JavaScript concepts
