# Quiz Application 🎯

A simple and interactive Quiz Application built using **HTML, CSS, and JavaScript**. This app allows users to answer multiple-choice questions and view their final score along with correct answers.

---

## 🚀 Features

* Multiple-choice quiz questions
* Instant navigation to the next question after selection
* Score tracking system
* Final result display with correct answers
* Clean and responsive UI

---

## 🧠 Quiz Topics Covered

* HTML basics
* CSS fundamentals
* JavaScript concepts

---



## ⚙️ How It Works

1. The quiz starts automatically when the page loads.
2. Each question is displayed with four options.
3. When a user selects an answer:

   * It is recorded
   * The app automatically moves to the next question
4. After all questions are answered:

   * Final score is displayed
   * Correct answers for all questions are shown

---

## 📊 Scoring System

* Each correct answer = **1 point**
* Total score is calculated at the end of the quiz

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
